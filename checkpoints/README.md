# External checkpoint

Place the compatible ViT-B/16 NPZ checkpoint here as:

```text
checkpoints/ViT-B_16.npz
```

The weight file is intentionally excluded from the source release. To keep it
elsewhere, set `CHECKPOINT=/absolute/path/to/ViT-B_16.npz`. See
[`../docs/DATA_AND_WEIGHTS.md`](../docs/DATA_AND_WEIGHTS.md).
